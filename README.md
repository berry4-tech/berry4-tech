### Things I've built

- **LabInsight AI**: Full-stack healthcare platform with a LangGraph agent orchestrating 5 tools, RAG over patient lab reports, role-based access, and a 12-case evaluation suite. [Live](https://group6-web-final-project.vercel.app) · [Code](https://github.com/berry4-tech/LabInsightsAI)
- **Orbital Threat Assessment**: ML pipeline flagging potentially hazardous asteroids across 958K NASA JPL records with a 450:1 class imbalance; final model reached 0.993 PR-AUC on held-out data. [Code](https://github.com/berry4-tech/Orbital_Threat_Assessment)
- **Greater Boston Lost & Found Ecosystem**: Multi-enterprise Java app connecting universities, MBTA, airports, and law enforcement, with a role-based approval workflow and MongoDB data model. [Code](https://github.com/berry4-tech/GreaterBoston_LostandFound_Ecosystem)
- **Transit-Shaped Signals**: Classifier separating genuine exoplanet transits from false positives in NASA Kepler and K2 light-curve data. [Code](https://github.com/berry4-tech/Machine-Learning-Technique-to-Identify-Transit-Shaped-Signals)
